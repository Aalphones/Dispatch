# Phase 1 — Fachlogik und Markdown (heikel)

Ziel: Der Server kann Markdown mit Code und Tabellen rendern, Dokumentfassungen mit Konfliktprüfung speichern, ältere Fassungen liefern, vergleichen und wiederherstellen, und die Werkzeuge der Registry nach Bereich gruppiert herausgeben. Noch keine Route, keine Oberfläche.

**Vor dem Start:** `git status` muss sauber sein. Der Plan `2026-11-12_zeitversetzt-veroeffentlichen` muss umgesetzt sein (README → Reihenfolge).

## Abnahmekriterien der Phase

- P1-AK1 `Markdown::toHtml` rendert `` `x` `` als `<code>x</code>` (Inhalt maskiert, keine Hervorhebung darin), Code-Blöcke zwischen Zeilen, die mit ``` beginnen, als `<pre><code>…</code></pre>` (Zeilen unverändert, maskiert, Sprachangabe ignoriert; fehlt die schließende Zeile, endet der Block am Textende) und Tabellen als `<table><thead><tr><th scope="col">…</th>…</tr></thead><tbody><tr><td>…</td>…</tr></tbody></table>`, wenn auf eine `|`-Zeile eine Trennzeile `|---|---|` folgt. Zellen bekommen Inline-Formatierung (fett, kursiv, Link, Code). Alles läuft wie bisher durch den Sanitizer.
- P1-AK2 Markdown ohne Backticks und ohne `|`-Zeilen ergibt Byte für Byte dasselbe HTML wie vorher (Prüfung unten).
- P1-AK3 `DocumentService::update(…, $baseRevision)` mit veralteter Basis wirft `DomainError('revision_conflict', …)` mit `details` `current_revision`, `actor`, `created_at`, `note` und schreibt nichts; mit passender Basis oder `null` speichert es wie bisher.
- P1-AK4 Zwei gleichzeitige `update`-Aufrufe mit derselben Basis ergeben genau eine neue Fassung und einen `revision_conflict` (Prüfung unten).
- P1-AK5 `restore` legt eine neue Fassung mit dem Inhalt der gewählten an, Notiz „Fassung N wiederhergestellt.“; unbekannte Fassung → `not_found`.
- P1-AK6 `revisionWithDiff` liefert HTML der Fassung und den Vergleich zur Fassung davor (`Diff::html` auf beide gerenderten Fassungen), bei der ersten `diff = null`.
- P1-AK7 `Registry::all()` liefert alle 33 Werkzeuge in Registrierungsreihenfolge, `groupOf()` je Werkzeug einen der sechs Bereiche aus README Entscheidung 6; `McpController::registry` ist `public static`; `Prompts::catalog()` liefert drei Einträge mit `text`.
- P1-AK8 ADR-029 liegt in `docs/decisions/`; `php -l` auf alle geänderten Dateien fehlerfrei.

- [ ] `Util/Markdown.php`:
  - Konstanten `FENCE_PATTERN = '/^```/'`, `TABLE_ROW_PATTERN = '/^\|.*\|[ \t]*$/'`, `TABLE_RULE_PATTERN = '/^\|?[ \t]*:?-{3,}:?[ \t]*(\|[ \t]*:?-{3,}:?[ \t]*)*\|?[ \t]*$/'`, `CODE_PATTERN = '/`([^`\n]+)`/'`.
  - `blocks()`: vor `singleLineBlock` zwei Prüfungen in dieser Reihenfolge — Zeile passt auf `FENCE_PATTERN` → Absatz abschließen, `[$html, $index] = self::fence($lines, $index)`; Zeile passt auf `TABLE_ROW_PATTERN` **und** die nächste Zeile auf `TABLE_RULE_PATTERN` → Absatz abschließen, `[$html, $index] = self::table($lines, $index)`.
  - `private static function fence(array $lines, int $start): array` — sammelt die Zeilen nach `$start` bis zur nächsten Zeile, die auf `FENCE_PATTERN` passt (diese wird verbraucht) oder bis zum Ende; Rückgabe `['<pre><code>' . self::escape(implode("\n", $gesammelt)) . '</code></pre>', $letzterIndex]`. Gesammelte Zeilen nur `rtrim`, nicht `trim`.
  - `private static function table(array $lines, int $start): array` — Kopfzeile = `$lines[$start]`, Trennzeile überspringen, dann Zeilen solange `TABLE_ROW_PATTERN` passt. `private static function cells(string $row): list<string>`: äußere `|` abschneiden (`trim($row)`, dann führendes und abschließendes `|` entfernen), an `|` teilen, jede Zelle `trim`. Kopfzellen `<th scope="col">` + `inline()`, Rumpfzellen `<td>` + `inline()`; fehlende Zellen einer Zeile als leere `<td></td>` auffüllen, überzählige verwerfen (Anzahl der Kopfzellen gilt). Docblock: „Ein `|` innerhalb einer Zelle trennt immer — auch in Backticks; ein Escape gibt es nicht.“
  - `inline()`: vor der Link-Ersetzung Code-Spannen per `CODE_PATTERN` in dieselbe Platzhalter-Liste wie die Links legen (`'<code>' . self::escape($match[1]) . '</code>'`), danach Links wie bisher in dieselbe Liste. Die abschließende Platzhalter-Ersetzung zweimal anwenden, damit ein Code-Platzhalter im Linktext ebenfalls ersetzt wird. Die Liste heißt künftig `$parts` statt `$links`.
  - Klassen-Docblock: „Code (Inline und Block) und Tabellen“ in die Aufzählung, Verweis „ADR-029“.
